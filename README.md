# Michael Klug — Business Homepage

A responsive, dependency-free static homepage for Michael Klug. The site positions Michael's work around platform engineering, cloud-native architecture, developer experience, and technical enablement.

## Preview locally

From this directory, run:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Project structure

- `index.html` — page content, metadata, and structured data
- `styles.css` — responsive layout, visual system, and motion
- `script.js` — mobile navigation, scroll state, and reveal behavior
- `assets/` — profile portrait, favicon, and social sharing artwork

## Deployment

The project has no build step. Deploy the directory to any static host, including GitHub Pages, Netlify, Cloudflare Pages, or an object-storage website.

Before a public commercial launch, add the final domain to the social metadata and include the appropriate Austrian legal/business disclosures for the operating entity.
